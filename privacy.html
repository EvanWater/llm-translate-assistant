LLM 翻译助手 · 隐私权政策

生效日期：2026 年 10 月 15 日 ｜ 版本：v1.0.0 ｜ 适用于 Chrome 浏览器扩展「LLM 翻译助手」

一、概述

LLM 翻译助手（以下简称"本扩展"）是一款完全运行在您的浏览器本地的翻译工具。本扩展的开发理念是隐私自持、数据不出本地。本政策说明本扩展如何处理信息，以及您拥有哪些控制权。

核心承诺：本扩展不收集、不上传、不出售任何用户数据，不设置任何统计埋点或第三方追踪 SDK，不经过任何开发者自建的中间服务器。

二、信息的收集与使用

本扩展不收集任何个人信息。具体而言：

  • 您输入或选中的待翻译文本仅在本机内存中处理，通过浏览器直接发送至您自行配置的大语言模型厂商 API，不经过任何第三方服务器；
  • 您配置的 API Key、BaseURL、模型名称等设置项仅保存在浏览器本地存储（chrome.storage.local），不会同步到您的浏览器账户，也不会被本扩展发送到除您配置的厂商 API 之外的任何地址；
  • 本扩展不读取您的浏览历史、Cookie、表单内容或与翻译无关的页面数据；仅在您主动触发翻译（划词、整页翻译或弹窗翻译）时读取所涉及的文字内容。

三、信息的存储与安全

  • 所有配置与翻译缓存保存在您本机浏览器的扩展存储中，卸载扩展即随之一并删除；
  • 数据传输仅通过 HTTPS 直连您配置的模型厂商接口，传输过程受 TLS 加密保护；
  • 本扩展不内置任何远程可执行代码，全部逻辑随扩展包一同发布并经商店审核。

四、第三方服务

本扩展本身不集成任何第三方服务。仅当您在设置中配置并主动使用翻译功能时，您指定的大语言模型服务商（如 OpenAI、DeepSeek、小米 MiMo 等）会收到您发起的翻译请求，该过程受各服务商自身的隐私政策约束。本扩展不代您选择或推荐服务商，也不与任何服务商共享超出单次翻译请求的信息。

五、权限用途说明

  • storage：在本地保存您的 API 配置、语言偏好与翻译缓存；
  • activeTab / scripting：在您主动触发翻译时，对当前标签页执行划词检测与整页翻译；
  • https://*/*：将翻译请求通过 HTTPS 直连发送至您自行配置的大语言模型 API 地址。

六、儿童隐私

本扩展不以未满 13 岁的儿童为对象，且因不收集任何个人信息，亦不涉及儿童数据的处理。

七、政策变更

若本政策发生实质性变更，我们将更新本页面的版本号与生效日期，并通过 Chrome 应用商店的版本更新记录向您告知。

八、联系方式

如对本政策有任何疑问，欢迎通过 GitHub 项目页提交 Issue 与我们联系：github.com（项目：translate-tool）。
